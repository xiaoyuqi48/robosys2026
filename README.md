# robosys2026

標準入力から受け取った数値を合計して、標準出力に表示するプログラムです。

## 使用方法

## average コマンド

標準入力から受け取った数値の平均値を計算して、標準出力に表示します。

使用例：

    seq 5 | ./average

実行結果：

    3.0

複数の数値も入力できます。

    printf "10\n20\n30\n" | ./average

実行結果：

    20.0

不正な入力や空入力の場合は、エラーメッセージを標準エラーに出力します。

Python 3 がインストールされた Linux 環境で実行できます。

    seq 5 | ./plus

実行結果：

    15

この例では、1から5までの数値を合計しています。

## sparkline コマンド

標準入力から数値を読み、1行の小さなグラフ（スパークライン）にして標準出力に表示します。
数値の並びの傾向を、端末でひと目で確認したいときに使えます。

    seq 1 8 | ./sparkline

実行結果：

    ▁▂▃▄▅▆▇█

数値は改行・空白・タブのどれで区切ってもかまいません。数値1つにつき1文字を出力し、
入力の最小値が ▁、最大値が █ になるように8段階に分けます。すべての値が同じときは、
すべて ▁ になります。

### オプション

| オプション | 意味 |
| --- | --- |
| `-l`, `--low LOW` | グラフの下限を数値で固定する |
| `-u`, `--high HIGH` | グラフの上限を数値で固定する |
| `-h`, `--help` | 使い方を表示して終了する |

範囲を固定すると、2つの系列を同じ縮尺で比べられます。

    printf "0\n50\n100\n" | ./sparkline -l 0 -u 100

実行結果：

    ▁▄█

固定した範囲を超える値は、いちばん近い端の段階に丸めます。

### エラー時の動作

次の場合は、エラーメッセージを標準エラーに出力し、標準出力には何も書かずに
終了ステータス 1 で終わります。

- 入力が空だった場合
- 数値でない値が含まれていた場合（例: `echo abc | ./sparkline`）
- `-l` の値が `-u` の値以上だった場合
- 不明なオプションを指定した場合

    echo abc | ./sparkline

実行結果（標準エラー）：

    sparkline: 数値ではありません: abc

## 必要な環境

- Ubuntu Linux
- Python 3
- Bash
